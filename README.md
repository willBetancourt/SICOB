# SICOB — Sistema de Comunicación Bidireccional

Prototipo académico para apoyar la comunicación entre personas sordas o con dificultades del habla y personas oyentes, mediante frases predefinidas, videos de Lengua de Señas Colombiana (LSC) y texto a voz.

## Ejecutar la maqueta
1. Descargue o clone el repositorio.
2. Abra `docs/Prototipo/index.html` en un navegador moderno (Chrome, Edge o Firefox). No requiere instalación ni servidor.
3. Explore los botones de comunicación, el módulo de texto libre y la sección de administración simulada. La maqueta usa contenido de demostración; no realiza traducción real a LSC ni sintetiza voz desde un servicio externo.
4. Para ver la presentación de la entrevista, abra `docs/Entrevistas/entrevista1/presentacion.html`.

## Estructura
- `docs/Contexto/`: investigación preliminar, hipótesis, actores y riesgos.
- `docs/Modelos/Negocio/`: procesos y diagramas del modelo de negocio.
- `docs/Modelos/Requerimientos/`: casos de uso y requisitos iniciales.
- `docs/Prototipo/`: maqueta navegable.
- `docs/Entrevistas/entrevista1/`: presentación breve y preguntas para el cliente.

## Alcance de esta versión
Es una base para validar ideas durante la primera entrevista. Las hipótesis, actores, prioridades y requisitos deben confirmarse con el cliente. El prototipo no sustituye intérpretes ni garantiza traducción automática.
